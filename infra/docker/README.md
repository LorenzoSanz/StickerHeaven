# Docker

Hay dos tipos de archivos:

## Dockerfile

Dockerfile es un archivo de texto que contiene una serie de instrucciones para construir una imagen de Docker.

## .yml

Levanta el contenedor con la serie de instrucciones que tiene Docker.

Se tiene que modificar el archivo `docker-compose.prod.yml`.
