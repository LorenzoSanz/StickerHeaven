# Nginx

Este es el servicio de proxy reverso para manejar solicitudes HTTP y HTTPS.

Utiliza Nginx para redirigir tráfico a la web y la API.
Se tiene que cambiar más adelante para configurarlo todo.

## Planes Futuros

Configurar nginx para proxy reverso, seguridad, cache y compresión. Además tiene que hacer de load balancer para distribuir el tráfico entre múltiples instancias de la web y la API.
